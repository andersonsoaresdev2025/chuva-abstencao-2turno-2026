# Licença dos dados

## Dados de análise do projeto — CC BY 4.0
Os arquivos produzidos pelas análises do projeto (classificações de risco a/b/c, coeficientes e sínteses
de correlação, redutos, estimativas de impacto, resumos executivos e sinais sociais curados em `data/`)
são disponibilizados sob a licença **Creative Commons Atribuição 4.0 Internacional (CC BY 4.0)**:
https://creativecommons.org/licenses/by/4.0/deed.pt_BR

Atribuição sugerida: *"Projeto Chuva × Abstenção Eleitoral – Segundo Turno 2026"*, com link para este repositório.

## Dados de origem pública — termos originais
Dados derivados de fontes públicas mantêm os termos das fontes originais:
- **TSE** (resultados eleitorais, Portal de Dados Abertos do TSE) – termos do TSE.
- **INMET** (alertas meteorológicos) – termos do INMET.
- **Open-Meteo** (previsão e arquivo histórico/ERA5) – dados sob CC BY 4.0, atribuição "Weather data by Open-Meteo.com".
- **IBGE** (códigos/malhas municipais) – termos do IBGE.

## Sinais sociais
`data/social/` contém **resumos** e **links** para publicações públicas (X, imprensa, órgãos oficiais).
O conteúdo original das publicações pertence aos respectivos autores/veículos; aqui só há resumo curto e link.
